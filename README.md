# Crypt Sound

将整条音轨按密钥扰乱，并在浏览器或本地恢复的实验项目。面向包含音乐的音视频，优先考虑有损转码后的音质与播放体验。

输入音视频 → CS2 音轨扰乱 → 上传视频 → 油猴解析音频链接 → 浏览器恢复播放。

恢复信息来自扰乱后的音轨本身，不依赖隐藏字幕、附件、原始音轨副本或在线密钥服务。视频编码只保留第一条视频流与替换音轨。

**本项目是音频扰乱工具，不是密码学加密工具。** 固定密钥映射会泄漏信号结构，没有随机 nonce 或认证标签；错误密钥不会报认证失败。不适用于敏感数据保密。扰乱音轨可能刺耳，请勿高音量直接试听。

## 功能与状态

- 文件编码、离线恢复、本地网页工作台；支持 WAV 音频以及 MP4 / MKV 视频音轨替换。
- B 站普通视频与分 P 的独立油猴解码，无需播放端安装 Python 或本地服务。
- 仅支持 CS2。CS1 文件需要从原音频重新编码；现有 CS2 文件与密钥保持兼容。
- 维护者已完成 **B 站端到端验证**；本地测试覆盖 PCM、AAC、Opus 和 Python / JavaScript 兼容性。验证范围及复现方式见[验证说明](docs/VALIDATION.md)。
- 油猴先下载完整音轨，再边解密边播放；当前限制为单 P 最长 15 分钟、音轨最大 96 MB。平台接口变化或转码处理仍可能影响可用性。

## 快速开始

需要 Python 3.11+，以及 PATH 中可用的 FFmpeg 和 ffprobe。以下命令在下载或克隆后的项目根目录运行（Windows / PowerShell）：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e .

# 密钥通过隐藏输入提示填写
.\.venv\Scripts\python.exe -m crypt_sound encode "输入.mp4" "上传版.mp4"
.\.venv\Scripts\python.exe -m crypt_sound decode "上传版.mp4" "恢复.wav"

# 打开本地网页工作台
.\.venv\Scripts\python.exe -m crypt_sound serve --open-browser
```

Linux / macOS 使用 .venv/bin/python 代替上述 Python 路径。Windows 完成环境安装后也可双击 start_gui.bat。

将 [crypt-sound.user.js](userscript/crypt-sound.user.js) 导入 Tampermonkey，刷新 B 站视频页，点击“音轨解码”，在独立窗口输入密钥并解析音频。详细权限、播放操作、命令参数和限制见[使用指南](docs/USAGE.md)。
