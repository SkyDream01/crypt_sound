## 快速开始（Windows / PowerShell）

需要 Python 3.11+、PATH 中的 FFmpeg（含 ffprobe），浏览器建议 Chrome / Edge，以及 Tampermonkey。

```powershell
cd crypt_sound
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -e ".[test]"

# 替换视频音轨。密钥通过隐藏输入提示填写，不写入命令行。
.\.venv\Scripts\python.exe -m crypt_sound encode "输入.mp4" "上传版.mp4"

# 离线恢复，用于上传前后试听对比。
.\.venv\Scripts\python.exe -m crypt_sound decode "上传版.mp4" "恢复.wav"

# 启动本地 GUI，保持此终端运行。
.\.venv\Scripts\python.exe -m crypt_sound serve
```

打开终端显示的本地工作台地址，可用网页界面加密或解密文件。音频文件加密后输出 WAV；MP4/MKV 视频会保留画面并替换音轨；解密结果为 WAV。单个上传文件最大 2 GB，处理结果下载链接有效 15 分钟，下载后或过期后会清理临时文件。也可以在工作台展开“实时标签页解码”。

Windows 上也可以双击项目目录中的 `start_gui.bat` 启动服务并自动打开工作台。脚本会检查并安装缺少的项目依赖；首次安装需要网络或本地 pip 缓存。关闭时在启动终端按 `Ctrl+C`。

也可以将音频文件编码为 `.wav` 载波，再自行合成视频。视频输出支持 `.mp4` / `.mkv`，视频流直接复制；如果源视频编码不兼容 MP4，请先转换视频或输出 MKV。命令不覆盖已有文件；失败时不会发布半成品。输出目录需已存在，并支持硬链接（本机 NTFS 支持）。仅处理输入的第一条音轨，输出双声道 48 kHz。

自动化可用 `--key-file "private.key"` 从 UTF-8 文件读取密钥，末尾换行会去除。保管好文件。密钥不写入输出视频。由于使用扰乱而非认证加密，**错误密钥不会报认证失败，只会产生另一种声音**。

## 油猴脚本与音频链接解码

**油猴 0.5.0 直接解析 B 站音频流地址，不再录音或共享标签页。** 播放端无需 Python、FFmpeg、本地服务；编码文件仍使用上面的 Python 工具。仅支持 CS2。

1. 将 `userscript/crypt-sound.user.js` 替换导入 Tampermonkey，保存并刷新普通 B 站视频页。更新时允许脚本访问 B 站 API 和音频 CDN。
2. 打开需要解码的视频及分 P，点击“音轨解码”，允许弹出独立窗口。
3. 输入音轨密钥，点击“解析音频并解码”。脚本暂停并静音原播放器，查询当前 BV/av 与分 P 对应的 CID，获取 DASH 音频链接，优先尝试高码率音轨；下载或格式解码失败时尝试备用地址及其他音轨。
4. 等待音轨下载并转成 PCM，首包恢复后即可在原页面播放视频，Worker 同时继续解密后续音频。跳到尚未解密的位置或播放追上解密进度时会暂停等待，缓冲就绪后继续。恢复声音跟随视频暂停、跳转、倍速和缓冲状态，恢复音量在独立窗口调整。无需将原播放器音量设为 100%，播放器音效不影响输入。
5. 保持两个窗口打开。停止或关闭解码窗口时恢复原静音状态；切换视频、分 P 或播放器节点时停止，需重新解析。重新开始会重新请求链接并要求填写密钥。

当前只支持普通视频 `/video/BV…`、`/video/av…` 及其 `p` 参数分 P，暂不支持直播、番剧和合集内不更新地址的特殊切集方式。优先读取脚本启动时页面已有且视频/CID 匹配的播放信息（仅使用一次且不超过两分钟）；缺少可用信息时，播放请求通过 nav 获取当前 WBI 参数，对排序后的查询参数生成签名，再请求 `/x/player/wbi/playurl`；API 优先使用浏览器普通 fetch 并携带已有登录状态，仅网络/CORS 失败时回退到油猴请求；HTTP 拒绝不会自动重试同一 API。API 和 CDN 请求均携带当前视频页 Referer。失败信息区分视频信息、WBI 参数、播放地址接口和音频 CDN，并显示 HTTP 状态、域名或接口错误码，不展示带签名的完整 URL。API 使用浏览器已有登录状态，无法访问的视频不会绕过权限。接口被风控、返回非 DASH 格式或平台接口变化时会提示失败。CDN 请求使用油猴普通请求模式，由浏览器按目标域处理 Cookie；不手动读取、复制或转发 B 站 Cookie；需要 Tampermonkey 的 `GM_xmlhttpRequest` 跨域权限（[官方文档](https://www.tampermonkey.net/documentation.php#api:GM_xmlhttpRequest)）。

此版先下载完整的**独立音轨**，通过浏览器 `decodeAudioData` 转成 48 kHz PCM，然后分块送入 Worker 恢复，每个已完成片段可立即进入播放调度，无需等整轨解密完成。不会下载视频画面。为限制内存占用，当前单 P 最长 15 分钟、音轨最大 96 MB；双声道输入与恢复 PCM 合计约 0.77 MB/秒，浏览器解码还有额外开销，长音轨可能占用数百 MB。首次等待时间取决于网络、音轨时长和 CPU，支持边解密边播放，但尚未实现分段下载、边下边播。

脚本内置 PBKDF2/SHA-256、导频同步、逆 DCT 与 Fourier 重采样；密钥只在本地 Worker 使用，不写入网络请求或持久化存储，提交 Worker 后清空输入框。Worker 每次确认后才发送下一块，避免输入队列积压。保留同步包在原音轨中的时间位置，缺失同步包的位置保持静音，避免后续声音整体前移。页面安全策略若阻止 Blob Worker，或浏览器不支持返回的音频格式，会提示失败。维护者已完成 B 站端到端验证；具体测试环境和记录见[验证说明](VALIDATION.md)。

原有 Python 本地工作台仍可用于文件编码、解码和可选的标签页实时捕获；它与油猴独立解码互不依赖。
