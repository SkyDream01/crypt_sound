音轨扰乱

生成经过时间扩散与频谱扰乱的 CS2 音轨。MP4/MKV 保留画面并替换音轨；音频文件输出 WAV。

解密时输入相同密钥。密钥不会写入输出文件。

选择文件并填写密钥即可开始。

CS2 / DECODE

文件解密

恢复 WAV

扫描文件中的 CS2 同步信号，恢复出立体声音频 WAV。视频画面不会复制到结果中。

错误密钥不会报错认证失败，只会生成另一种声音。

选择文件并填写密钥即可开始。

! 安全说明：CS2 是可转码恢复的音轨扰乱实验，不是 AES 等密码学加密。每秒音量、静音位置和重复内容仍可能泄漏，请勿用于保护敏感或机密内容。
实时标签页解码从浏览器捕获正在播放的扰乱音轨＋
  1. 用 Chrome 或 Edge 播放已编码视频，保持 1 倍速、音量 100%。
  2. 输入音轨密钥，开始后选择视频所在的浏览器标签页并共享标签页音频。
  3. 不要共享整个桌面或本解码页；先调低系统音量，确认恢复后再调高。

等待启动

实时恢复约有 1–2 秒启动延迟，画面不会自动延后。停止共享或关闭本页会结束解码。
